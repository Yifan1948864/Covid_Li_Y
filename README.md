# Project Repository

This repository contains the code and final report for the MDS project, *Changing Drivers of Protective Health Behaviour Across Multi-Policy Conditions in Australia During COVID-19*.

## Folder Structure

### `Part A Reproduction Code`

Contains the code used in Part A to reproduce the analytical framework of Ryan et al. (2025). 
This reproduction served as the technical baseline for the final project.

### `Project code`

Contains the code for the final analysis, 
including data cleaning, data integration, policy-intensity classification, train-test splitting, Random Forest and XGBoost modelling, model evaluation, feature-importance estimation, and figure generation.

### `Project Final Report`

Contains the final written project report and the files used to produce it.
